## Research Application & Trajectory

This computational foundation supports quantitative modeling in cancer metabolism, enzyme kinetics, and biotransport[span_15](start_span)[span_15](end_span), including:
1. Automated peak detection, baseline correction, and integration for FPLC UV absorbance chromatograms[span_16](start_span)[span_16](end_span).
2. Non-linear parameter estimation for allosteric enzyme kinetics (Michaelis-Menten / Hill formulations).
3. 1D/2D finite-difference modeling of interstitial fluid pressure (IFP) and convective transport gradients in solid tumors.
